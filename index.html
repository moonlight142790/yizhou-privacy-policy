译舟隐私政策

更新及生效日期：2026 年 10 月 30 日

运营者：王业兴
联系邮箱：1427909882@qq.com

译舟提供本机文档翻译与对照阅读服务。使用本应用不需要注册译舟账号。翻译功能需要联网并由使用者自行提供通义千问 API Key。

一、处理的信息与用途

您主动导入的 TXT／Markdown 文档、选定的语言、翻译风格和术语，应用生成的背景笔记及译文、您进行的校订和翻译进度，用于在当前设备提供文档管理、翻译和阅读功能。文档、笔记、译文及进度保存在应用私有目录；默认模型名称保存在本机偏好设置中。

您主动输入或从文件导入的阿里云百炼 API Key 仅用于本次运行中的服务请求认证，应用不将密钥写入文档库、偏好设置或安装包。退出应用后需要重新输入或导入。请自行妥善保管原始密钥文件。

二、联网翻译与第三方处理

您点击“开始翻译”或“继续翻译”并确认后，应用通过 HTTPS 向阿里云百炼通义千问接口发送文档正文分段、前后文、全文背景笔记、语言及术语约定，并接收背景笔记和译文。连接检查会发送少量测试文字。API Key 作为请求认证信息发送给阿里云百炼。译舟运营者不设置中转服务器或云端文档库，也不接收上述正文和密钥。

请不要导入无权处理的内容或不宜提供给第三方模型服务的敏感内容。服务商如何存储或使用请求数据，以阿里云百炼的服务协议与隐私政策为准；本应用不能替您删除服务商的请求记录。模型调用可能产生您自己的阿里云账户费用。停止已发出的请求仍可能计费。

三、权限、存储与保留

应用声明网络权限，用于访问上述 HTTPS 接口。文档的选择与导出通过系统文件选择器按您的操作完成，不扫描其他文件。应用不申请相机、麦克风、定位或通讯录权限，不接入广告、统计分析或第三方登录 SDK。

本机文档保留至您在应用内删除或卸载应用。卸载会清除应用私有目录中的文档和进度，应用不提供云端恢复；请在卸载前导出需要保留的译文。您主动导出的文件由您自行管理，应用内删除文档不会删除已导出的文件。设备系统备份和您自行同步的文件依各自设置处理。

四、您的选择与权利

您可以在阅读页查看、搜索、校订、导出或删除本机文档；在设置中清除本次会话载入的 API Key。您可以不提供 API Key，仍可导入和阅读本机文档，但无法调用翻译功能。应用没有译舟网络账号，因此无账号注销流程。

如需咨询或反馈本应用的数据处理，可通过上方公开客服邮箱联系运营者。针对您在阿里云百炼账户和模型服务中的数据，请使用服务商提供的账户与隐私渠道。

五、未成年人及政策更新

未成年人应在监护人指导下使用本应用，特别留意第三方 API 调用可能产生的费用。应用不主动索取未成年人身份信息。若应用功能、数据处理方式或运营者信息变化，我们会更新本政策并在应用内或发布页面告知。
